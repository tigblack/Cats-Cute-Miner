# Cat Miners — выбор стиля

Четыре концепт-арта основного игрового экрана. Во всех вариантах показаны котики-копатели, камни и кристаллы, сундук, кузница, шахта, ворота и интерфейс. Это концепты оформления, а не скриншоты реализованной игры и не эталон раскладки уровня из JSON. Показанные числа служат оформлению макета, баланс не менялся.
