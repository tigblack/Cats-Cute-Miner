# Звуки Cat Miners

Звук игры — три слоя (`Docs/Visual/ART_DIRECTION.md`, раздел 9):
- **звуки действий** — мягкие казуальные записанные сэмплы CC0 (ТЗ 14, `PIXEL_STYLE_GUIDE.md` §8): удары по камню, металл,
  стекло, колокольчики, настоящие кошки, джинглы пиццикато и стил-драма. У ударов по кристаллу добавлен синтезированный
  стеклянный «тинь»;
- **музыка** — две оригинальные темы, синтезированные и аранжированные кодом (`Tools/Audio/music.py`), без сэмплов
  и сторонних материалов;
- **атмосфера** — фон пещеры и редкие события, тоже синтез кодом (`Tools/Audio/ambience.py`).

Синтез через `AudioClip.Create` в `Sfx` остаётся только запасным вариантом на случай, если файла нет. Лицензии
и ссылки — [`CREDITS.md`](CREDITS.md).

> **Файлы `.ogg` есть только на ПК** (`Assets/Game/Resources/Audio/`): Mutagen не синхронизирует бинарные форматы,
> поэтому на хабе этой папки «нет». Это нормально — не пересоздавайте файлы. `.meta` к ним Unity создаёт сама при импорте.

## Как это устроено

- `Runtime/Audio/Sfx.cs` при создании загружает `Resources.Load<AudioClip>("Audio/<имя>_<n>")` для n = 0, 1, … до первого
  пропуска (или один файл `Audio/<имя>`). Если не найдено ни одного — пишет предупреждение в лог и синтезирует мягкую замену
  (щипки «маримбы/колокольчика» на пентатонике, глухие удары; без шумовых всплесков).
- Импорт `.ogg` — настройки Unity по умолчанию (`Decompress On Load`, **Preload Audio Data выключен**), поэтому `Sfx.Create`
  сразу вызывает `LoadAudioData()` для каждого клипа: разовая цена при старте (≈ 1 МБ PCM), а первый удар, мяу или джингл
  в игре не грузит и не декодирует файл в главном потоке.
- 6 голосов `AudioSource`: у каждого звука своя громкость, разброс высоты, минимальный интервал между запусками и приоритет
  (частый удар не обрывает джингл). Вариант выбирается случайно и не повторяет предыдущий.
- Джинглы ворот/выхода (уровень 2) и запуска шахты/автоматизации/порога (уровень 1) на 80 % своей длины глушат звуки наград
  `Upgrade` и `ChestOpen` из той же пачки событий **при любом порядке событий**: награда, запущенная в том же кадре раньше
  джингла, останавливается в момент его старта (Play и Stop в одном кадре не слышны). Случаи: сундук ворот, сундук выхода
  перед финалом кампании, обычное улучшение при пороге, улучшение карты или сундук, автоматизировавшие шахту. Если джингл
  сам не зазвучал (интервал, нет голоса, звук выключен), награда остаётся. Джингл не важнее текущего не звучит.
- Кит UI вызывает `UiSound.PlayClick/Open/Close/Denied`; `Sfx.Create` подставляет туда свои методы, `OnDestroy` снимает их.
  Отказ (`denied`) у кнопки кита решается по состоянию **на момент нажатия**: если действие кнопки само её выключило
  (улучшение карты потратило копии, взят последний бесплатный сундук), после щелчка отказ не звучит.
- Переключатель в настройках сначала применяет значение, потом щёлкает: включение звука слышно, выключение — тишина.
- Выключенный звук (`Sfx.Enabled = false`) глушит и то, что уже звучит.
- События офлайна не озвучиваются — ни при загрузке, ни при возврате из фона (или после остановки кадра > 1 с):
  `GameController` отбрасывает их, итог показывает окно «Пока вас не было» (ТЗ 12.3) со своим звуком открытия.
- Все файлы собраны скриптом [`build_sfx.py`](build_sfx.py) (обрезка, фильтры, сведение слоёв, нормировка до −18 дБFS RMS
  звучащей части с пиком не выше −1 дБFS, OGG Vorbis моно 44,1 кГц). Поэтому громкость в таблице — это и есть микс.

70 файлов, ≈ 5,0 МБ.

## Группы громкости и настройки

Группы — кодом, без ассета AudioMixer (`Runtime/Audio/AudioMix.cs`): итоговая громкость источника = громкость звука ×
группа × Master; при выключенном звуке — 0.

| Группа | По умолчанию | Что входит |
|---|---|---|
| Master | 1,0 | всё |
| Music | 0,6 | `MusicPlayer` |
| SFX | 1,0 | `Sfx`, звуки UI |
| Ambience | 0,7 | `Ambience` |

Значения, общий переключатель звука, вибрация и «Меньше эффектов» хранятся в сохранении игрока
(`PlayerSettingsState`) и меняются в окне настроек: ползунки Master, Музыка, Звуки, Атмосфера. На паузе приложения
(`OnApplicationPause`) весь звук приостанавливается (`AudioListener.pause`) и продолжается с того же места.

рендерится вместе с хвостом реверберации, хвост складывается в начало, последний такт гармонически ведёт к первому.

**Воспроизведение** (`Runtime/Audio/MusicPlayer.cs`): трек выбирает оформление шахты (`PresentationCatalog.MusicOf`:
пещера — «Кристальная глубина», штольня и выработка — «Тёплая штольня»). Смена — перекрёстная, 3 с (первый запуск — 2 с).
Чтобы долгая сессия не утомляла, после двух циклов своего трека один цикл звучит другой. Окна и перестройка поля музыку
не перезапускают.

Импорт: `Streaming`, качество Vorbis 0,6. Мастера в высоком качестве — `Docs/Audio/masters/music_*_master.ogg` (на ПК).
Пересборка: `Tools/.venv/bin/python Tools/Audio/music.py --out Temp/audio/music [warm] [crystal]` — результат
детерминирован.

## Как заменить или добавить звук

1. **Просто заменить файл.** Положить на ПК `Assets/Game/Resources/Audio/<имя>_<n>.ogg` (или `.wav`) — имена из таблицы,
   варианты подряд с `_0`; лишние варианты (`_4`, `_5`, …) подхватятся сами (до 8). Громкость и интервалы — в `Sfx.Create`.
   Новый файл должен быть уже «готовым»: моно, без тишины в начале, короткий хвост, громкость около −18 дБFS RMS.
2. **Пересобрать из исходников.** Рецепты — в [`build_sfx.py`](build_sfx.py) (`RECIPES`). Исходные паки
   (ссылки в `CREDITS.md`) скачиваются на ПК в `build/audio-src/` (`curl.exe -L -o …zip <url>`, `tar -xf`) и копируются на хаб
   в `Temp/audio/src/` (через base64: `on-remote powershell -Command "[Convert]::ToBase64String([IO.File]::ReadAllBytes('…'))"`).
   Затем на хабе: `Tools/.venv/bin/python Docs/Audio/build_sfx.py --src Temp/audio/src --out Temp/audio/out [имена…]`
   (venv только на хабе: `python3 -m venv Tools/.venv && Tools/.venv/bin/pip install numpy scipy soundfile`).
3. **Перенести на ПК.** Бинарники не синкаются, а большой stdin через `on-remote` ненадёжен, поэтому: упаковать `tar` →
   `base64 -w 76 > Docs/Audio/_transfer_<имя>.b64` (текст синкается) → на ПК
   `powershell -File Tools/Audio/unpack_transfer.ps1 -Name <имя> -Dest Assets/Game/Resources/Audio` (раскодирует в `build/`,
   печатает SHA-256, распаковывает `tar`) → сверить SHA-256 с хабом → удалить `_transfer_<имя>.b64`.
4. Новый звук для нового события: рецепт в `build_sfx.py`, поле `Cue` + `Load(...)` + публичный метод в `Sfx`, вызов в
   `GameController.Present`, строка в этой таблице и в `CREDITS.md`, запасной синтез в `Sfx.Fallback`.

Лицензия — только CC0 (допустимо CC-BY с записью автора в `CREDITS.md`); NC/ND/GPL/неизвестные — нельзя.

## Что проверить на слух (ПК / устройство)

- Много котиков бьют одновременно: удары не сливаются в треск и не заглушают награды; при 6+ работниках — ровный негромкий фон.
- Камень рассыпается + монетка в одном кадре звучат вместе приятно, монетка не «звенит» (ФНЧ 6 кГц).
- Мяу: четыре разных коротких голоса, не раздражают при частом найме; разброс высоты ±5 %.
- Ворота: джингл стил-драма, звук сундука-награды ворот не накладывается.
- Порог уровня: джингл запуска, обычный звук улучшения не дублирует его.
- Улучшение карты или сундук, автоматизировавшие шахту, и сундук выхода в конце кампании: слышен только джингл.
- Кнопки: «буп» не щёлкает; отказ (`denied`) не дублируется при тапе по неактивной кнопке, которая ещё и отклоняет команду,
  и не звучит после успешного улучшения карты или взятия последнего бесплатного сундука.
- Настройки: включение звука подтверждается щелчком.
- Динамит: «поп-бум» без перегруза на телефонном динамике (низ ≥ 60 Гц, основная энергия 100–800 Гц).
- После офлайна и возврата из фона: никакого «залпа» — только звук открытия окна «Пока вас не было», без «+N» и вспышек
  под ним.
- Первый удар, мяу, щелчок и джингл после запуска звучат без задержки и без рывка кадра.
- Удары по кристаллу, дереву и металлу отличаются от удара по камню, но остаются той же мягкой семьи.
- Оружие: молот глуше кирки, у дробилки — частая дробь, пила и бензопила не визжат и не утомляют при 5+ котиках с
  инструментами, бур не звенит, «пиу» лазера мягкий, а не «бластерный».
- Музыка: стык цикла не слышен (≈ 2:20 и ≈ 2:27), смена трека при переходе в пещеру — плавная, без провала громкости;
  мелодия не утомляет за 15–20 минут; на телефонном динамике слышны маримба и колокольчики, бас не гудит.
- Атмосфера: фон не слышен как шум, события редкие и не похожи на звуки игры (капля не путается с наградой).
- Ползунки громкости меняют звук сразу; после перезапуска значения те же; на паузе приложения тишина, после — продолжение.

## Подключение CatOutpostV2

Новая сцена использует `Scripts/Runtime/Outpost/OutpostAudio.cs`, события
`OutpostBoardView.Cue` и существующие клипы `Resources/Audio` из таблиц выше.
Их авторство/лицензии сохранены; исходники музыки и атмосферы —
`Tools/Audio/music.py` и `Tools/Audio/ambience.py`. Отдельных новых фонограмм
для этого режима не добавлено. Клип никогда не зачисляет деньги и не выдаёт награду.

| Событие | Источник/ID | Микс и ограничение |
|---|---|---|
| Шаг котика | `click_0` | 0.045 × SFX gain, pitch 0.65, один голос, не чаще 0.25 с |
| Сдача порции | `coin_0` | 0.28 × SFX gain, pitch 0.95–1.15, два голоса по местам склада, интервал 0.12 с |
| Полная сумка, подбор, очередь | `coin_0` | 0.1 × SFX gain, pitch 0.7/1.15, один голос, интервал 0.2 с |
| Удар по материалу | `Sfx.Hit(material)` | Прежние варианты камня/дерева/кристалла/металла, ограничение Sfx |
| Разрушение / открытие сектора | `Sfx.Break` / `Sfx.GateOpen` | По событию представления |
| Команда собралась / наём | `Sfx.ExitOpen` / `Sfx.Meow` | По событию, без старой пушки |
| Улучшение / экипировка | `Sfx.Upgrade` / `Sfx.Chime` | После успешного commit |

Master/Music/SFX/Ambience меняются через новый HUD и хранятся в новом профиле.
Группы реализованы `AudioMix`, без отдельного AudioMixer-ассета. При pause/focus
приостанавливается AudioListener; офлайн не воспроизводит все прошедшие удары
и доставки залпом. Музыка выбирается через существующий MusicPlayer с плавной сменой.

Документальная запись нового режима и её фактический звуковой поток находятся
в `Docs/Reports/outpost/recording/` после запуска `OutpostGameplayRecordingTests`.
Наличие сигнала в записи не подтверждает субъективную проверку баланса громкости,
стыка цикла и воспроизведения на телефонном динамике; статус этих проверок —
`Docs/Rework/VALIDATION_V2.md`.
