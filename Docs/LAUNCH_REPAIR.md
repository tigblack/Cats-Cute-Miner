# Запуск после восстановления проекта

Проверено 17 октября 2026 на Mac с Apple Silicon, Unity 6000.6.4f1.

## Запуск

- Готовое приложение на этом Mac: `Builds/macOS/Cat Miner.app`. Откройте его в Finder.
- В Unity: откройте `Assets/Game/Scenes/CoreGame.unity` и нажмите Play.
- Повторная сборка приложения: меню **Cat Miners → Build → macOS App**. Приложение открывается в портретном окне; параметры проекта восстанавливаются после сборки.
- Для читов: `Builds/macOS/Cat Miner Dev.app`, сборка через **Cat Miners → Build → macOS Development App**. В редакторе Dev-панель доступна при Play.

## Переход между уровнями в Dev

Откройте **DEV 4**. Кнопки **+1**, **+10**, **−1**, **−10** сразу загружают шахту относительно текущей. Для прямого перехода введите номер **1–144** в поле и нажмите **Load** или **Enter**. Недопустимый номер показывает подсказку, переход за край кампании ограничивается первой или последней шахтой.

Чит сохраняет Main и автоматически переключается в отдельный профиль Debug. Кнопка **Main** возвращает основной прогресс. При ошибке записи сначала нажмите повтор сохранения: новая шахта появляется после успешной записи. Обычная сборка `Cat Miner.app` не включает Dev-панель.

Сборки и журналы проверок находятся в игнорируемых каталогах и не входят в Git.

## Исправления

- Устранены конфликт `SafeArea`, устаревшие вызовы поиска объектов, предупреждения вибрации, покупок и минимальной версии Android.
- Обновлены устаревшие вызовы в примерах Facebook SDK и pragma шейдера TMP.
- Для JSON-моделей удалены ненужные атрибуты сериализации Unity: данные по-прежнему читает Newtonsoft.Json. Атрибуты типов, используемых `JsonUtility`, сохранены.
- Через Unity обновлены устаревшие метаданные TMP и Facebook SDK с сохранением GUID.
- Восстановлены и проверены 129 ресурсов: библиотеки SDK, звуки, шрифты и ресурсы примеров. Новые звуки восстановлены из рецептов проекта; Nunito — с исходными метриками проекта и стрелкой U+2192.
- Отключены неиспользуемые ресурсы постобработки в рендерах URP: при запуске приложения больше нет предупреждений о вырезанных шейдерах постэффектов.
- Из PC-рендера удалён неиспользуемый SSAO: в Dev-сборке он обращался к удалённым при сборке ресурсам и вызывал ошибку при старте. Пиксельные материалы игры используют Unlit.
- Исправлены ссылки на Playable и UnityEditor в отдельной проверке компиляции PlayMode-тестов.
- Обновлены тестовые данные старого сохранения и проверки ввода с учётом обстановки шахты и положения камеры.

## Проверки

- Данные и доступность всех 144 шахт проверены в Unity.
- 64 теста конфигурации, сериализации, сохранений и аутентификации: пройдены.
- 10 PlayMode-тестов: пройдены. Проверены старт, ввод, добыча, окна, сохранение, сброс и загрузка старого профиля.
- Отдельная проверка компиляции Runtime, DevTools, Playable и PlayModeTests: 0 ошибок, 0 предупреждений.
- Стартовая сцена в Play: состояние `Playing`, поле, HUD и шрифты загружены, ошибок и предупреждений нет.
- Нативная сборка macOS ARM64 успешна; приложение запущено. Ошибок сборки нет, при старте нет предупреждений о постэффектах.
- После исправления читов пройдены ещё 7 PlayMode-проверок: прямые переходы кнопками, ввод номера через Load и Enter, границы кампании, сохранность Main, расчёт времени при переключении профиля и повтор после ошибки записи. Результаты: `Docs/Reports/LevelCheatRepair/`.
- Нативная Dev-сборка macOS собрана и запущена; после удаления SSAO в журнале запуска нет ошибок и предупреждений. При сборке остаются два предупреждения внешних служб, перечисленные ниже.

Журналы и результаты: `Docs/Reports/LaunchRepair/` на Mac. Длительные проверки полного прохождения кампании не входят в эту проверку запуска.

## Что требует исходных файлов или настройки служб

В исходном ZIP вместо двух изображений иконки остались указатели Git LFS:

- `Assets/Game/Art/Store/CatsCuteMinerIcon.png`
- `Assets/Game/Art/Store/CatsCuteMinerIconBackground.png`

Оригинальное оформление не подменялось. Для его восстановления нужен Git-клон с доступом к LFS-объектам исходного репозитория. Проверка: `python3 Tools/check-assets.py` на Mac.

Сборка также сообщает о ненастроенных Unity Services и Facebook App ID. Их полноценная настройка требует действительных идентификаторов и доступа к соответствующим службам. Эти два предупреждения не мешают локальному запуску. Восстановление и запуск игры не означают готовность Android-релиза, покупок или аналитики.
