# Документы этой игры

Пользователь 14.10.2026 согласовал аудиторию с детьми младше 13 лет, нейтральную проверку возраста, детский режим без MAX/Meta/рекламы и подготовку отдельных документов. Общие страницы студии не изменялись.

Оба файла — локальные проекты текстов. Они ещё не являются утверждёнными или опубликованными Privacy Policy/Terms и не должны подаваться в Console как действующие документы.

Перед публикацией:

- Перечитать готовую возрастную проверку, согласия и actual native initialization. Подтвердить отсутствие MAX/Meta/рекламы и необязательной аналитики для детей и неизвестного возраста, включая автоматические native SDK старты.
- Проверить магазин, разрешения родителя и реальную серверную выдачу, recovery/удаление, перечень данных каждого установленного SDK и фактически подключённых сетей.
- Подтвердить официальный публичный email, сроки хранения серверных данных и процедуру ответа родителю. Пока неизвестные сведения явно оставлены в текстах.
- Утвердить окончательные тексты и постоянные HTTPS URL для этой игры. Публикация файлов или изменение общих страниц потребуют отдельного поручения; здесь этого не сделано.

Фактические источники выявленного конфликта:

- https://multicastgames.com/policy — раздел Children: аудитория от 16 лет.
- https://multicastgames.com/termsofuse — раздел Eligibility: использование с 16 лет.
- https://support.applovin.com/en/max/android/overview/privacy — не инициализировать MAX для детей; mixed audience требует разделения.
- https://support.google.com/googleplay/android-developer/answer/9867159 — нейтральная проверка возраста для mixed audience, отдельные требования к детской рекламе.
