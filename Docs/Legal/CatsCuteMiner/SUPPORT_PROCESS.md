# Обработка запросов игроков и родителей — Cat Miners: Idle Tycoon

Принято владельцем проекта 19.10.2026 для `com.multicastgames.catscuteminer`.

Ответственный: владелец проекта, текущий пользователь этого чата. Его фактическое подтверждение: «Я — беру процесс на себя; почта работает, доступ к исполнению есть». Рабочий канал: support@multicastgames.com. Новое подтверждение заменяет прежнее состояние «процесс не подтверждён». Это подтверждение организации работы, не доказательство уже выполненного удаления конкретного игрока.

1. Регистрировать обращение и дату получения в закрытом журнале поддержки; определить применимый срок ответа. Не сохранять реальные обращения или персональные данные в этом репозитории.
2. Уточнить игру, вид запроса, заявителя и связь с ребёнком, если применимо. Запрашивать только соразмерное подтверждение. Не требовать пароль, auth token, платёжную карту, полный день рождения ребёнка или новую покупку. При наличии использовать ссылку на заказ Google Play; при её отсутствии помочь установить соответствующие записи.
3. Найти относящиеся к игре guest-account, purchase/order/delivery записи и связанные данные получателей аналитики, если они действительно отправлялись. Защищённым игрокам не приписывать события, которые не передавались.
4. Для доступа/исправления предоставить относящиеся к заявителю данные безопасным способом после проверки полномочий. Для удаления выполнить удаление/анонимизацию в доступных студийных системах и необходимые запросы соответствующим провайдерам через разрешённые административные средства. Конкретные API удаления не выдумывать; при необходимости использовать доступного администратора сервиса.
5. До удаления проверить незавершённые покупки и обязательное хранение. Для каждого исключения зафиксировать категорию, основание, критерий окончания хранения и ответственного. Не оставлять весь профиль бессрочно только из-за одного удерживаемого финансового документа. Решения о законных сроках хранения согласовывать с ответственным студии за соответствующие обязанности.
6. Проверить исполнение во всех затронутых системах и сообщить заявителю результат, оставшиеся категории и причины. Временная блокировка аккаунта не подменяет удаление. В журнале оставить минимально необходимое доказательство исполнения с доступом только уполномоченных лиц.
7. Разъяснить отдельно: сброс прогресса и удаление приложения не удаляют серверные записи; удаление данных не является возвратом платежа. Данные Google, обрабатываемые им самостоятельно, находятся вне контроля студии. Доступ к незавершённым покупкам согласовать до очистки данных устройства.

Никаких писем или запросов удаления от имени пользователя агентом при подготовке этих документов не отправлено. Реальный кейс исполнения ещё не проверялся.
