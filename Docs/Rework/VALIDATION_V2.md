## Исправленные дефекты

- Запись после восстановления из backup больше не заменяет последний валидный
  backup повреждённым main. Проверены аварии каждого шага с поддержкой и без
  поддержки Replace и выбор более нового backup.
- IOException от Replace не запускает разрушительный fallback: файловая система
  могла уже переименовать main в backup. Повтор сохраняет тот же снимок.
- Пустой GoingHome пробуждается при освобождении доступного груза и меняет задачу
  в ближайшей клетке; текущая доля ребра сохраняется.
- MoveStuckTicks восстанавливает потерянный таймер/некорректный путь один раз
  через 3 секунды. Медленное непрерывное ребро не считается зависанием.
- Разность UTC офлайна не переполняет Int64; крайние часы проверены отдельно.
- Уменьшение рюкзака сохраняет переполненную сумку и запрещает новый набор
  до доставки, включая котиков в пути, подборе и добыче.
- Обычное затемнение перехода учитывается в новом run без окна «Пока вас не было».
- После ошибки офлайн-записи исходная сводка объединяется со временем ожидания
  повтора; новое значение обновляет уже открытое окно.
- Время, потраченное на порционный офлайн-расчёт, входит в дальнейшее онлайн-время.
- New Debug не перезаписывает результат ещё работающего Finish.
- В портретном HUD выделено место для числа котиков; после перехода видны два
  работника и сохранённый бонус кирки при нулевых местных уровнях.

Критические проверки контроллера: самостоятельная доставка при открытой базе,
касаний груза без начисления, реальный pointer tap/drag и отмена жеста модальным
окном, повтор одного подготовленного commit, объединённые pause/focus,
8-часовой cap/остановка в текущей шахте, ошибки профиля без reset, разделение
Main/Debug, награда/переход после записи. Синтетическому вводу в тесте явно
разрешён фокус Game View пакетного Editor; после теста настройки восстановлены.

### Сверка замечаний независимого аудита

- Переполнение UTC и неиспользованный MoveStuckTicks относились к промежуточному
  коду. В итоговой версии разность вычисляется через BigInteger до ограничения,
  а потерянный таймер движения восстанавливается через 3 секунды. Регрессии
  ExtremeClockDelta и OutpostMovementRecoveryTests входят в прошедший EditMode.
- Подсказки покупки кирок и найма не имеют таймера завершения: после разовых
  пояснений они доступны до соответствующей покупки. При недостатке денег
  подсказка скрывается и возвращается при доступной цене. Самостоятельная
  покупка во время предыдущего пояснения также засчитывается по событию ядра.
  Поэтому описанная в аудите потеря подсказки от одного лишь истечения времени
  не подтверждается текущим Evaluate/OnEvent.
- Pivot груза (18, −14) в обрезанном прямоугольнике 9×15 соответствует общему
  pivot (20, 4) исходного холста 40×40: сборщик вычитает смещение обрезки.
  Слои view используют одну точку pose, отдельного смещения груза нет.
  Отрицательное значение предусмотрено [ART_NAMES.md](ART_NAMES.md); менять
  его на pivot полного холста означало бы сместить спрайт. Реальные рендеры
  сцены и проверка генератора не выявили подтверждённого дефекта выравнивания.
- Ограничение геометрических overrides остаётся действительным и указано
  в разделе приёмки; ни одной из текущих 144 карт такое исправление не требуется.

## Производительность Editor

Фактический стенд: Lenovo 82RG, AMD Ryzen 5 6600H, 12 логических CPU,
15 557 MB RAM, AMD Radeon Graphics, Windows 11 build 26200,
Direct3D11, Mono, Editor PlayMode. Кадр замерялся при **640×480**,
aspect override 9:16, targetFrameRate 60, vsync 0; отдельные снимки 1080×1920
сделаны вне окна замера. Эти значения не описывают Android-производительность.

В каждой зоне 12 котиков, открытая база, одновременно наблюдались добыча,
перенос, два обслуживания и груз на земле. Прогрев 2 с, по одному образцу
около 5 с (297–298 кадров). Доступный Debug-комплект q1, законные Team/Pickaxes
×1 до cap. Только в отдельном Debug run CoinBase увеличен в 100 000 раз до
первых доставок для финансирования нагрузки; это не прогон честного баланса.
Обычный Main не изменён. Остальные ветки не ускорялись.

## Ограничения приёмки

- APK не собран: каталог AndroidPlayer найден, но отсутствуют **Android SDK,
  Android NDK и OpenJDK**, включая проверку внешних путей Preferences.
  Машинный результат: [build-android.json](../Reports/build-android.json),
  `result = ModuleMissing`, exit 3. Установка через Unity Hub → Add modules →
  Android Build Support (SDK & NDK Tools, OpenJDK), затем `BuildApk -Target Ci`.
- Нет подтверждения Android/IL2CPP, touch на устройстве, фонового жизненного
  цикла Android и FPS/GC телефона. Editor не заменяет эти проверки. Не подтверждены
  бюджет 1 КБ полного игрового кадра и нагрузка с абсолютным максимумом партий.
  Исторический замер производительности использует 12 котиков и 8 часов офлайна;
  отдельные замеры максимума карточек (17 котиков, 15 часов) ещё не выполнены.
- Ручное прохождение шахт 1–3 и ручная приёмка ворот 5/10 не выполнены;
  покрытие ядром, автоматическими сценовыми тестами и сценарной записью
  обозначается отдельно. Субъективное прослушивание длительной музыки,
  стыка цикла и телефонного динамика не подтверждено.
- b2 = b1 + `TapDamageFactor`; с полной ареной zone1 и cards-1 политика C идёт 254.9 с
  (4.25 минуты, в уточнённом ориентире полной арены 3–5 из §12.6 ТЗ).
- b2 + cards-1 — измеренный стартовый профиль: ранняя покупка наступает быстрее
  ориентира, поздние изолированные шахты с заработанным комплектом проходят за
  5.1–6.6 минуты вместо ориентира 8–15. С улучшением карточек темп ещё быстрее
  (примерно 3–4 минуты на выбранных поздних шахтах). Продуктовая настройка темпа
  требует проверки на игроках; параметры этой проверкой не менялись.
- Геометрические overrides реализованы только как добавление целей на свободные
  клетки (`AddTokens`); удалить или сдвинуть исходный объект override не может.
  Единственное исключение — `zone1-full-arena-1` (решение владельца продукта,
  ТЗ 8.5): +36 целей в zone1. Исходным 144 картам overrides по-прежнему не нужны.
- Удар кирки игрока проверен ядром, сценовыми тестами мыши и рендерами; касание
  пальцем на телефоне, ощущение частоты ударов и громкость нового звука удара
  человеком не проверены.

Эти ограничения отделены от реализованного автоматического игрового цикла.
Запуск и повторяемые команды — [README_REWORK.md](README_REWORK.md).
