# Docs/TZ — техническое задание и материалы аудита

Для **предстоящей смены жанра** актуально полное [ТЗ 2.1](Cat_Miners_Auto_Incremental_TZ_v2.1.md): автоматическая добыча, физическая доставка монет, общие локальные улучшения и постоянная экипировка. Оно имеет приоритет над противоречащими игровыми правилами старого режима. Подготовка ТЗ не означает, что код проекта уже переделан.

- [Замечания к 2.0 и исправления](REVIEW_Outpost_v2.0_to_v2.1.md) — объяснение решений и границы выполненной проверки.
- [Исходник 2.0](source/Cat_Miners_Auto_Incremental_TZ_v2.0.md) — точная архивная копия нового вложения пользователя.
- `analysis/outpost_v2_audit.py` и `outpost_v2_audit.json` — воспроизводимый аудит 144 карт и новых контрольных формул; статическая расчистка 144/144. Скрипт не запускает Unity или симуляцию работников.
- `Cat_Miners_Unity_Core_TZ_v1.3.md` — историческое ТЗ реализованного прототипа с merge/ручным назначением, полезное для понимания текущего кода и переиспользования. Его gameplay не переносится автоматически в новый режим.

Исполнителю передать ТЗ 2.1, существующий проект и `Assets/Game/Data/Source/json-data.json` (SHA-256 `8975a5a09dce8e2675d06b751c50b5cac80da3988f8ed098910492c442f85ee5`).

Уточнения 10 октября согласуют карточки с формулами цены/удара, пределами команды
и офлайна, переходами, сохранениями и приёмкой. Все 61 карточка сопоставлены
в [CARD_EFFECT_MAPPING.md](../Rework/CARD_EFFECT_MAPPING.md); их новые коэффициенты —
`Assets/Game/Resources/Outpost/card_rules.json`. Текущие замеры и результаты Unity:
[BALANCE_V2.md](../Rework/BALANCE_V2.md), [VALIDATION_V2.md](../Rework/VALIDATION_V2.md).
Старые результаты и бюджеты без карточек не заменяют замеры b2 + cards-1.

- `analysis/` — проверки, на которых основана версия 1.2. Все скрипты запускаются как `python3 <script>.py <путь к json-data.json>`:
  - `verified_facts.md` — сводка проверенных фактов о JSON и Unity-проекте.
  - `zones_summary.csv` — эталонные значения по всем 144 зонам для автотеста импорта (генерирует `zones_summary.py`).
  - `control_values.py` — пересчёт контрольных значений Приложения C ТЗ.
  - `check_zones.py`, `special_objects.py`, `reachability.py`, `sector_components.py`, `cards.py`, `rock_rewards.py`, `gacha.py` — проверки сеток, геометрии, достижимости, карточек, наград и сундуков.
  - `audit/` — замечания к версии 1.1 по направлениям:
    - `DATA` — данные;
    - `CONS` — согласованность;
    - `SCOPE` — охват JSON;
    - `TECH` — Unity;
    - `GAME` — геймплей;
    - `FORMULA` — формулы.

    Там же:
    - вердикты верификаторов (`V_*.json`);
    - результаты веб-исследования (`web-reference.json`);
    - финальная проверка самой версии 1.2 (`FINAL_REVIEW_v1.2.md`): 54 замечания, все внесены в документ.
  - `scratch/` — рабочие скрипты агентов аудита, включая сопоставление с публичными таблицами референса (`web_compare*.py`, `web_chests.py`) и упрощённую симуляцию темпа (`formula/sim*.py`).

Папка `Docs/` лежит вне `Assets/`, Unity её не импортирует.
