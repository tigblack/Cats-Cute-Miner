4. Редкость каждой карты: Legendary с вероятностью 1/LegendaryWeight, иначе Rare 1/RareWeight, иначе Uncommon 1/UncommonWeight, иначе Common; вес 0 — невозможно. Соответствие: Common = Rarity 1, Uncommon = 2, Rare = 3, Legendary = 5; Rarity 4 и 6 в v1 не выпадают.

7. MimicId — только визуальный тип сундука; поля не наследуются.
8. Результат определяется и сохраняется одной транзакцией с RNG из сохранения, до анимации.
