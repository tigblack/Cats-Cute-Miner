**Решение по масштабу** (пункт 4 задания).

Задание предлагает попробовать клетку ≈ 48 px и котика 48×64 в кадре 360×640. Проверка:
- поле 7 клеток + стены ≈ 8,3 клетки на 1080 px;
- при 32 px на клетку пиксель арта = 4,0 экранных пикселя — тот же, что у UI-кита (4 единицы Canvas);
- при 48 px он был бы ≈ 2,7 экранного пикселя: дробный, неравные пиксели («миксели») рядом с UI в 4 px и мерцание при прокрутке.

Поэтому масштаб остаётся **32 px на клетку**, котик — холст 40×40, единая сетка пикселей поля и UI. Подробно — в `ART_DIRECTION.md`.

## План

1. **Котики.**
   - Новые позы: дыхание 6, потягивание 10, ходьба 8, добыча 10, перенос 4, появление 8, радость 6.
   - 6 ступеней экипировки: кирка, каска, снаряжение.
   - Отметины окрасов.
   - Дедупликация одинаковых слоёв в сборке атласа; атлас 2048×1024.
   - `CatView`: машина состояний кадров по реальным состояниям, ходьба при перемещении.
2. **Звук.**
   - Синтезатор и аранжировка двух треков (numpy, `Tools/Audio`), бесшовный цикл.
   - Атмосфера: фон пещеры и редкие события.
   - Новые SFX: выбор, удары по материалам.
   - `AudioMix`: группы Master/Music/SFX/Ambience; `MusicPlayer` с плавной сменой; пауза приложения.
3. **Мир.**
   - 3 стадии повреждения камней (силуэт).
   - Контактный акцент удара, сколы по материалу.
   - 3 оформления окружения по зонам.
   - Состояния шахт.
   - «Меньше эффектов», импульс камеры для редких событий.
4. **UI.**
   - Настройки: ползунки громкости, вибрация, уменьшение эффектов.
   - Ползунок в ките.
   - Обход всех окон.
   - Снимки 9:16 / 9:19.5 / 9:20.
5. **Проверка и передача.**
   - Документы, каталог ассетов, QA.
   - Кадры «после», листы спрайтов на ПК.
   - Запись.
