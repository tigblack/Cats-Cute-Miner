# AppMetrica: диагностика Android

Лёгкие логи `MC-AM` работают независимо от консоли. Они показывают причину отказа
в инициализации, SHA-256 SDK-ключа, настройки сбора, возврат `Activate`, проверку
нативного `AppMetricaProxy.isActivated()`, вызов/возврат/ошибку `ReportEvent` и
`SendEventsBuffer`. Значения ключей, параметры событий и сообщения исключений
не выводятся. В памяти хранятся последние 500 строк.

`EventSubmitted` означает, что вызов SDK вернулся без исключения. Это не
подтверждение доставки. Проверка Java-прокси также подтверждает только активацию.

В отдельном локальном диагностическом APK флаг
`CATMINERS_APPMETRICA_DIAGNOSTICS` включает `AppMetricaConfig.Logs` и кнопку
**AM logs** поверх HUD. Доступны фильтр, прокрутка, остановка автопрокрутки,
режим Native only и копирование безопасного текста. Консоль не меняет consent,
покупки или игровой прогресс. В обычной сборке этот флаг отсутствует, подробные
нативные логи и консоль выключены.

В диагностической сборке непривилегированный Android logcat-читатель наблюдает
логи собственного UID. В консоль он пропускает только `Event sent` для известных
игровых событий, без параметров и идентификаторов. Для закреплённого Android SDK
7.12.0 это сообщение возникает после принятого серверного ответа:
[ReportTask.onPostRequestComplete](https://github.com/appmetrica/appmetrica-sdk-android/blob/v7.12.0/analytics/src/main/java/io/appmetrica/analytics/impl/ReportTask.java#L420).
Оно показывается как `NativeAccepted`. Очищенная очередь сама по себе этого не
доказывает: SDK удаляет данные и при HTTP 400.

Если встроенный читатель недоступен или `NativeAccepted` отсутствует, приём
сервером остаётся неподтверждённым. Нужен приватный `adb logcat` с тегом
`AppMetrica`. Сырой лог может содержать параметры событий и частичный ключ;
его не следует помещать в публичные отчёты или отправлять без очистки.

Сборка на Mac (эмулятор автоматически не запускается):

```bash
python3 Tools/GooglePlay/build-appmetrica-diagnostic-macos.py --version 0.1.5 --version-code 6 --label automatic
```

Результат: `build/private/appmetrica-automatic-0.1.5-6-20261020/cat-miners-appmetrica-automatic.apk`.
Это локальный Development APK с debug-подписью, а не обновление для Play Console.
Чтобы поставить его поверх приложения с другой подписью, сначала потребуется
удалить ту установку и её тестовые данные.

С версии 0.1.5 базовая AppMetrica запускается автоматически: не нужно открывать
Privacy Policy, выбирать возраст или включать провайдера перед первым событием.
Проверка свежей установки выполняется без открытия настроек. Отдельно проверяются
явное отключение, его сохранение и повторный запуск. Перед активацией отключены
рекламные идентификаторы; геолокация, автоматическое денежное revenue,
автоматические deeplink-события и crash reporting также выключены. Собственные
технические идентификаторы SDK остаются частью его работы.

Настройка AppMetrica в Settings → Analytics & privacy позволяет отключить будущую
отправку без выбора возраста. Старое явно сохранённое отключение сохраняется при
миграции. Adjust, Meta и денежное revenue сохраняют отдельные возрастные ограничения.
В версиях 0.1.3/0.1.4 действовало ручное включение AppMetrica.

Ключ сверяется с полем **API key (для использования в SDK)** приложения
**6374386**, а не Post API key. В отчётах сохраняются результат сравнения и
хеш, значение ключа не публикуется.
