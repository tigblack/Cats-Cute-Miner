# MAX: отложено до второго релиза

Решение владельца 19 октября 2026: первый релиз игры без рекламы.

Сюда перенесены прежние `Assets/MaxSdk` и их метаданные. Каталог находится вне `Assets`, поэтому Unity не импортирует
настройки с типами отсутствующего SDK и не включает их в сборку. Клиентский ключ также сохранён в игровом конфиге;
в отчёты его не выводить. Зарегистрированный рекламный блок в кабинете сохранён.

В первом релизе MAX отсутствует в UPM, ссылках сборки, Android-зависимостях и символах компиляции; `AdsEnabled` выключен.
Обычный Editor скрывает рекламные предложения. Симуляцию в тестах явно включает `SimulateRewardedOffersForTests`,
который отсутствует в Android player.

Подключение SDK, нативных согласий, рекламных сетей и проверка показов выполняются отдельным обновлением для второго релиза.

22 октября2026: по новому запросу владельца MAX восстановлен в Assets/MaxSdk, UPM, Android define и runtime assembly. Этот каталог сохраняется как историческая копия. Новый APK использует официальный Unity8.6.6/Android13.6.4 и прежние проверки согласия; веб-реклама остаётся выключенной.
