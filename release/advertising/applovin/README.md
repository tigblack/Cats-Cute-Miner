Кампания привлечения игроков **не создана и не запущена**. Страны и дневной бюджет в USD оставлены пустыми по поручению владельца. Автоматического запуска нет. В игре по-прежнему отключены MAX и реклама.

Новое название для магазина — **Cat Miner: Idle Tycoon**, короткое — **Cat Miner**. В библиотеку SuperLeo проекта `e4e954f1-59a9-479a-821f-be7eed9aff47` загружены `CatMiner_Axon_Factories_30s_en.mp4` и `CatMiner_Axon_Endcard_1080x1920.png`; существующая `icon-512.png` подходит без изменений. Загрузка в библиотеку студии не означает отправку в рекламную сеть или прохождение модерации AppLovin.

Откройте `index.html`, чтобы посмотреть новый английский ролик и графику. В `assets/` находятся MP4 1080×1920, финальный кадр 1080×1920 и иконка 512×512. Ролик показывает реальные фабрики из Unity: цепи → доставка → продажа → автоматизация. Продолжительность — номинально 30 секунд; контейнер с аудио — 30,02 секунды. Покупки, включая случайные предметы, обозначены на финальном кадре. Проверены параметры файлов и пять кадров; полное прослушивание и сравнение с финальной Android-сборкой ещё нужны.

`campaign-draft.json` — локальный план для заполнения, **не тело API-запроса**. Он содержит тексты объявления, ссылки на файлы и явный запрет активации. `tracking-plan.json` отделяет подтверждённые ID Adjust от незавершённой настройки Axon. Ключей, сессий браузера и платёжных данных в пакете нет.

Создана собственная ссылка Adjust **Cat Miner Android Axon**, link token `25sohm3z`; настоящие click/impression URL со штатными макросами перенесены в черновик. Это отдельный токен ссылки, не SDK app token. Передача данных партнёру остаётся отключённой. Сами tracking URL не открывались для теста: это создало бы искусственные клики/показы. Шаблоны содержат device-ID/IP макросы провайдера и требуют проверки допустимой аудитории и приватности перед использованием.

## Что оставить пустым

Страны, дневной и общий бюджет, цена установки/ставка, способ торгов, дата начала и ID рекламного аккаунта. Собственные ссылки атрибуции уже получены и записаны. Предложение CPI не является выбранной настройкой. Язык этого креатива — английский; это не выбор стран. Бразилия исключена из первого выпуска и должна оставаться исключённой из будущего таргетинга.

## Что ещё требуется до запуска

1. Завершить отдельные действующие документы игры, подписанный Android AAB, внутреннюю проверку и публикацию страницы Google Play. Предполагаемый URL магазина в черновике пока не подтверждён как действующая страница.
2. Подтвердить доступ к собственному рекламному аккаунту AppLovin/Axon и возможность рекламировать смешанную аудиторию игры по правилам платформы. Возрастной рейтинг 6+ не задаёт рекламный таргетинг. Защита младше16/неизвестного возраста сохраняется, optional telemetry для них отсутствует.
3. В Adjust завершить подключение Axon собственным подтверждённым account SDK key, сохранить и перечитать разрешённые настройки и сопоставление `fv23mx` → `In-App Checkout`. Собственные click/impression URL получены и перечитаны; проверить допустимость их макросов и будущей аудитории перед трафиком. SDK app token `cdbdt3hkj56o` не является токеном рекламной ссылки.
4. Загрузить файлы в подтверждённый собственный creative set и дождаться проверки платформой. Эти файлы подготовлены локально, приём платформой пока не подтверждён.
5. После решения владельца заполнить страны, бюджет, оптимизацию и ставки. Проверить доступность игры в этих странах и исключение BR. Получить отдельное явное поручение на запуск; сам факт заполнения полей запуск не разрешает.

## Почему нет «приостановленной кампании» в кабинете

[Документация Campaign Management API](https://support.applovin.com/en/growth/promoting-your-apps/api/axon-campaign-management-api) требует бюджет, таргетинг и tracking при создании и помечает `status` как игнорируемое поле операции создания. Поэтому передача `PAUSED` не подтверждает безопасный черновик. При пустых согласованных полях используется этот локальный пакет.

[Спецификация креативов](https://support.applovin.com/en/growth/promoting-your-apps/welcome-to-applovin/creative-specs-and-guidelines) и [настройка Adjust](https://support.applovin.com/en/growth/promoting-your-apps/track-and-optimize/adjust) проверены16.10.2026. Фактический результат проверки кабинетов записан в `account-readback.json`. Параметры и хеши файлов — `artifact-checks.json`, происхождение игрового материала — `creative-source.json`.
